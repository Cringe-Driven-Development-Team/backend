# Доступ к блокнотам и клонирование

Контракт Go API находится в `spec/openapi.json`, пути ниже — относительно `/api/v1`. Для всех запросов обязателен `X-BFF-Key`. Браузер вызывает BFF, а не Go API напрямую.

## Настройки доступа

Новый блокнот и любая копия доступны владельцу. Владелец может добавить адресных читателей и включить ссылку. Список `GET /notebooks` содержит собственные блокноты.

`GET /notebooks/{id}/sharing` возвращает настройки владельцу:

```json
{"link_token":null,"readers":[{"id":2,"login":"reader","role":"viewer"}]}
```

`PUT /notebooks/{id}/sharing` атомарно заменяет список читателей и состояние ссылки:

```json
{"link":true,"readers":[{"login":"reader","role":"commenter"}]}
```

Логины разрешаются без учёта регистра. При повторах применяется последняя роль адресата, владелец исключается. Разрешения хранятся по ID пользователя и сохраняются после смены логина. Пустой `readers` отзывает адресный доступ. Некорректный ввод даёт `400 validation_error`, неизвестный логин — `400 unknown_login`. В обоих случаях сохраняются прежний список и токен.

`link: true` сохраняет активный токен или создаёт его. `link: false` отзывает ссылку. При переключении ссылки передавайте действующий список читателей. Миграция сохраняет прежние адресные разрешения как `viewer`. Для блокнотов, ранее открытых по ID, владелец при необходимости включает новую ссылку.

`GET /users/suggest?q=rea&limit=10` возвращает только `{items:[{id,login}]}`. Требуется сессия; поиск по ASCII-префиксу после обрезки пробелов (1–32 буквы, цифры или `_`), без учёта регистра. `_` буквальный. limit — 1–20, по умолчанию 10. Текущий пользователь исключён. Общий Redis-бюджет — 60 запросов за 60 секунд на пользователя, превышение — 429 `rate_limited`. Ошибка Redis не разрешает запрос.

## Чтение и BFF

Для чтения требуется действующая сессия. По ID метаданные, содержимое и [комментарии](cell-comments.md) доступны владельцу и адресным читателям. Закрытый, удалённый и отсутствующий блокнот дают одинаковый 404.

`GET /shared/{token}` и `GET /shared/{token}/content` возвращают метаданные и снимок ячеек по действующему токену. Удалённый или заменённый токен, неизвестный токен и удалённый блокнот дают одинаковый 404. У посетителя только по ссылке счётчики комментариев равны `0` и `{}`. Для действий, доступных по адресу или владению, используйте ID блокнота. Содержимое включает сохранённые результаты исполнения и ETag. Ответы чтения и настроек используют `Cache-Control: no-store`.

| Посетитель | is_owner | can_edit | can_manage_sharing | can_comment | can_clone |
|---|---|---|---|---|---|
| Владелец | true | true | true | true | true |
| viewer | false | false | false | false | true |
| commenter | false | false | false | true | true |
| Только по ссылке | false | false | false | false | false |

## Копия

`POST /notebooks/{id}/clone` с телом `{"name":"Моя копия"}` доступен владельцу и адресным читателям с действующей сессией. Имя обрезается по краям и должно содержать 1–128 Unicode-символов; одинаковые имена разрешены. Ответ — 201 с новым Notebook.

Копия имеет нового владельца, ID, даты, ревизию и source_version ячеек. ID ячеек уникальны в пределах блокнота и могут сохраняться. Копируется полный документ: metadata/extra, исходники, порядок и типы ячеек, attachments, outputs, execution_count и признак усечения. Runtime, задания, workspace, комментарии и разрешения не копируются. Ошибка записи откатывает весь новый документ. Копия не зависит от дальнейшей судьбы исходника.

PUT, clone, edit, сохранение результата и delete используют общую блокировку строки исходного блокнота. Clone проверяет права после захвата блокировки отдельным запросом, поэтому завершившийся отзыв доступа учитывается и после ожидания. Чтение content использует repeatable-read снимок.

## Совместная проверка с frontend#260 и frontend#261

На двух учётных записях проверьте вход по публичной ссылке, смену `viewer` на `commenter`, отзыв роли и ссылки, а также независимое редактирование и запуск копии. Доступные действия интерфейса определяются полем `access`. При включении ссылки BFF сохраняет список адресатов из текущих настроек.
